Logbook
Wiring 
  RS485 sensor side
  ─────────────────
   sensor V+ ──── external 12–24 V PSU (+)
   sensor GND ─┬─ external PSU (−)
               └─ T-CAN485 GND  ← common ground is mandatory
   sensor A  ──── T-CAN485 RS485 "A"
   sensor B  ──── T-CAN485 RS485 "B"
   ↑ swap A/B if no response — labelling on cheap sensors is unreliable
   For runs > ~3 m, add a 120 Ω termination resistor across A–B at the
   far end (and a second one at the T-CAN485 end for very long buses).

  CAN side (to Cerbo GX VE.Can port)
  ──────────────────────────────────
   T-CAN485 CAN-H ── CAN-H ── … ── Cerbo VE.Can RJ45 pin 7
   T-CAN485 CAN-L ── CAN-L ── … ── Cerbo VE.Can RJ45 pin 8
   T-CAN485 GND   ── shield/drain (optional)
   Bus must be terminated 120 Ω at BOTH ends. Use Victron's
   RJ45 VE.Can terminator on the Cerbo end; add a 120 Ω resistor
   across CAN-H/CAN-L at the T-CAN485 end (or buy a second terminator).
   Bitrate is fixed at 250 kbit/s — set the Cerbo VE.Can port to
   "VE.Can & NMEA 2000 (250 kbit/s)" in Remote Console.
Configuration field reference

Slave address

Modbus device ID (1–247). Cheap sensors usually ship as 1.

Baud / parity

Common values are 9600 8N1 (default of most level transmitters).

Function code

0x03 Read Holding Registers — most level sensors. 0x04 Read Input Registers — some sensors expose readings here instead.

Register address

Where the level reading lives in the device's Modbus map. Try 0x0000 first, then 0x0004.

Scale factor

Multiplier from the raw register value to millimetres.

  • Raw is already mm → 1.0
  • Raw is cm → 10.0
  • Raw is metres × 100 → 10.0
  • Raw is 0–10000 ‰ of full scale → sensor_range_mm / 10000

Sensor range (mm)

Full-scale measurement depth. Used to convert mm → percent for PGN 127505.

Tank capacity (L)

Physical tank volume. Sent as the absolute capacity field of PGN 127505 so the Cerbo GX can show litres alongside %.

Polling interval (ms)

How often to read the sensor. PGN 127505 transmits every 2.5 s regardless; polling faster than that just makes the local readout snappier.

NMEA 2000 / VE.Can

The bridge announces itself on the bus with an ISO Address Claim (PGN 60928) and then transmits Fluid Level (PGN 127505) every 2.5 s with Tank Type = Fresh Water and Instance = 0. The Cerbo GX assigns a Tank instance automatically and shows the value on its Tanks page. If multiple bridges share a bus, give each a different tank instance in code.

Until the address claim completes, the device source address is 254 and frames are not transmitted (they would be silently dropped by the stack). The N2K Source / Tx readout shows when the claim has settled.

Probe walkthrough
  1. Wire the sensor and power it. The bridge must be powered too.
  2. Sign in, go to the Configure tab, and hit Start probe. Phase 1 (~3 s) finds plausible bauds; phase 2 sweeps slave addresses and registers on the surviving lanes.
  3. Watch the hits table. A row with a sane-looking value (e.g. depth in mm matching the tank) is your sensor.
  4. Click Use to apply that hit's settings to the Configure form, then click Save.
Troubleshooting
  • Modbus errors keep increasing — check A/B polarity (try swapping), verify common ground between the sensor PSU and the T-CAN485 GND, confirm the baud and slave address.
  • Cerbo GX doesn't show the tank — verify the VE.Can port mode (Settings → Services → VE.Can port → 250 kbit/s + NMEA 2000), both ends of the bus terminated, and that the N2K source on this page is not 254.
  • Web UI freezes during probe — refresh; the probe runs in a background task and shouldn't block. If it does, file a bug.
  • WiFi STA won't connect — re-save SSID and password, check the LED is purple (AP-only) before retrying.
Lost password recovery

The admin password regenerates on every boot until you change it via the web UI. To recover: reboot the device with a serial monitor attached (115200 baud) — the new password prints on startup. All other settings are preserved.
